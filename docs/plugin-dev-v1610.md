# 插件开发文档：v1.6.10 公告简报卡片化 + 公告列表/详情合并

> 关联：plugin_host（工作台公告简报）、notice（列表 / 详情 / 发布）
> 版本：v1.6.10 · 文档日期：2026-10-23
> 状态：**✅ 已实现并部署**（237 项测试全绿 + Docker 重建）

## 一、需求

### A. 工作台「公告简报」

1. 不再使用单一容器，每条公告渲染为独立卡片；
2. 卡片横向流式排布，自动换行；
3. 单卡保留公告标题、发布时间；「查看全部公告」按钮放在卡片组下方单独一行（右对齐）；
4. 卡片沿用 `r-card` 圆角 / 阴影风格；
5. 公告数据与交互不变（卡片标题链接到内联详情）。

### B. 公告列表页 / 详情页合并

1. 左侧导航不变；顶部保留公告列表工具栏（标题 + 发布公告）；
2. 主体在列表页内联渲染详情，不再跳转独立详情页；
3. 详情排版：标题放大为主标题；发布人 / 时间 / 已读人数 / 状态收拢为辅助信息；正文独立区块（行高 1.9 + 内边距 + `--r-paper-2` 底）；
4. 点击列表任一条切换详情（`?notice=<id>`，同页刷新）；保留返回逻辑；样式与全站卡片统一。

## 二、设计口径

| 项 | 决策 |
|---|---|
| 列表 + 详情布局 | 工具栏下 `row g-4`：左 `col-lg-5` 列表卡片，右 `col-lg-7` 内联详情卡片；<lg 堆叠 |
| 选中公告 | `?notice=<id>`；缺省选中排序第一条（置顶优先）；非法 id → 404 |
| 已读 | 进入列表页即对当前选中公告幂等记已读；列表「已读/未读」标记与已读人数实时 |
| 旧详情链接 | `/plugins/notice/<id>/` 302 重定向到 `/plugins/notice/?notice=<id>`（兼容工作台旧链接 / 外链） |
| 发布后跳转 | 发布成功跳转到 `?notice=<新 id>`，直接看到内联详情 |
| 工作台卡片 | `col-12 col-md-6 col-xl-4` + `r-card h-100`；标题链接、置顶徽标、发布时间；「查看全部公告」独立一行右对齐 |
| 数据 / 交互 | 公告查询、已读去重、发布权限、上链信号均不变；旧模板 `notice_detail.html` 删除 |
