# 插件开发文档：v1.6.9 图表双卡等宽等高

> 关联：plugin_host（工作台共享看板模板）
> 版本：v1.6.9 · 文档日期：2026-10-23
> 状态：**✅ 已实现并部署**（按要求未跑自动化测试，视觉验证交由负责人）

## 一、需求

「插件分布」与「组织人员」两卡：

1. **等宽**（并排，各占一行的一半）；
2. **等高**，尺寸完全一致；
3. 内部图表自适应卡片容器，不挤压、不溢出；
4. 原有内容、图例、交互逻辑不变。

## 二、设计口径

| 项 | 决策 |
|---|---|
| 等宽 | 保持 `col-12 col-lg-6`（≥lg 并排各半，<lg 堆叠） |
| 等高 | 两卡均 `r-card h-100`；同一 `row` 拉伸 → 卡片高度等于行高，完全一致 |
| 图表尺寸 | 两卡图表容器统一 `width:100%;height:300px`（插件分布 240 → 300，与柱状图一致）；饼图紧凑图例（v1.6.6）不变 |
| 自适应 | ECharts 适配器自带 `ResizeObserver`，容器宽度变化时 `chart.resize()`；容器宽度 100%，无横向溢出；固定高度 300px 不挤压卡片内容 |
| 内容不变 | 饼图 / 柱状图数据、图例、tooltip、点击跳转与卡片文案未改 |

## 三、改动面

| 文件 | 动作 |
|---|---|
| `plugin_host/templates/home_dashboard.html` | 插件分布卡恢复 `h-100`；图表 240 → 300px（与组织人员一致） |
| 文档 | 本文件 + roadmap / README / constraints |

无新表、无迁移、无 Python / CSS 规则变化。

## 四、验收

1. ≥lg 屏两卡并排、宽度一致、卡片底边齐平；
2. 环形图与柱状图容器同高，重绘无挤压 / 溢出；
3. 内容、图例、交互与数据不变；<lg 屏仍上下堆叠。
