## 二、设计口径

| 项 | 决策 |
|---|---|
| 信息合并 | 状态徽标与签到 / 签退时间由两行合并为同一行（`d-flex flex-wrap align-items-center gap-2`），省掉原说明行 |
| 高度收紧 | 标题 `mb-3 → mb-2`；控件区 `mt-3 → mt-2`；卡片内无多余纵向空行 |
| 等高 | 两卡恢复 `h-100`（行默认 stretch），两卡等高；内容已压缩，拉伸空隙极小 |
| 不变 | 状态判断分支、签到 / 签退表单、字段与提交逻辑不变 |
