# 插件开发文档：v1.6.13 用户管理 + 角色权限码排版优化

> 关联：user（用户管理 / 角色管理）
> 版本：v1.6.13 · 文档日期：2026-10-23
> 状态：**✅ 已实现并部署**（237 项测试全绿 + Docker 重建）

## 一、需求

### 用户管理

1. 操作区风险配色：编辑（蓝色文字链接，维持）、冻结权限（蓝色主按钮）、禁用（红色危险按钮）；
2. 按钮内文字居中、同行等高、间距均匀；超管行弱化为灰色小字「超管（不可操作）」；
3. 表格对齐规范：垂直居中、表头一致、角色标签统一、状态标签统一、行高内边距均衡；
4. 右上「+ 新建用户」与全站主按钮一致；
5. （可选）冻结 / 禁用已有确认弹窗（保留）。

### 角色管理

1. 权限等级标签统一样式、垂直居中、单元格留白；
2. 权限码流式换行、等距、浅蓝徽标、标签组顶部对齐、不横向溢出；
3. 全表单元格垂直居中、行高适配折行、编辑按钮垂直居中；
4. 右上「+ 新建角色」与全站主按钮一致。

## 二、设计口径

| 项 | 决策 |
|---|---|
| 表格 | 两页统一 `r-table r-table--roomy align-middle` + `table-responsive` + `th scope`；与角色 / 审批 / 部门页一致 |
| 用户操作区 | 单元格内 `d-flex align-items-center gap-2`；编辑为 `r-offset-hover` 文字链接；冻结 / 解冻 / 启用为 `r-btn`；禁用为 `r-btn--danger`（v1.6.11 定义）；表单 `m-0`；操作列 `text-nowrap` |
| 超管行 | `text-muted` + `font-size:.75rem` 弱化展示，无操作控件 |
| 角色标签 | 用户页角色、角色页权限码均 `d-flex flex-wrap gap-1`（角色页 `align-items-start`），徽标统一 `r-badge` / `r-badge--blue` |
| 角色表格 | `table-layout:fixed` + `colgroup` 固定 ID / 名称 / 等级 / 成员 / 操作宽度，权限码列占剩余宽度 → 自动折行不横向拉长 |
| 确认弹窗 | 冻结 / 禁用保留原有 `onclick confirm`（未新增 / 未改文案） |
| 页头 | `flex-wrap gap-2`，右上按钮 `r-btn` 与全站一致 |
| 不变 | 字段、查询、状态机、审批 / 上链逻辑、权限判断全部未改 |
