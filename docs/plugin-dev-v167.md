## 一、需求

1. 核心数据看板四张卡片的操作按钮**风格一致**（「审批中心」原为 plain 线框，改为与其他三个相同的主按钮）；
2. 四个按钮文本**去掉「→」**。

## 二、设计口径

| 按钮 | 改动 |
|---|---|
| 进入待办 | 去掉尾部 `→` |
| 去打卡 | 去掉尾部 `→` |
| 审批中心 | `r-btn r-btn--plain` → `r-btn`（与其余三个一致），去掉尾部 `→` |
| 打开插件开关 | 去掉尾部 `→` |

- 箭头为模板中的独立字符（不在 `{% trans %}` 内），无需改 `.po`；
- 按钮仍居底、水平居中、四按钮同一基线（v1.6.5 布局不变）；
- 其余链接 / 图表 / 数据不动。

## 四、验收

四按钮视觉一致、文本无箭头、底部居中对齐；其余看板内容不变。
