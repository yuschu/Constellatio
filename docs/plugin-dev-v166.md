# 插件开发文档：v1.6.6 插件分布卡片紧凑化

> 关联：plugin_host（工作台共享看板模板）、charts/echarts（饼图 option）
> 版本：v1.6.6 · 文档日期：2026-10-23
> 状态：**✅ 已实现并部署**（按要求未跑自动化测试，视觉验证交由负责人）

## 一、需求

「插件分布」卡片内：

1. 移除图表下方多余空白区域；
2. 环形图、图例（含分页控件）、说明文案紧凑排布，减少无效留白；
3. 卡片高度自适应内容，不预留大片空白（不被右侧组织人员卡片拉伸）。

## 二、设计口径

| 项 | 决策 |
|---|---|
| 卡片高度 | 去掉 `h-100`（不再随同行「组织人员」卡片等高）；卡片高度 = 内容高度，行内顶部对齐 |
| 图表高度 | 300px → 240px；ECharts 饼图半径 38%→60%、圆心 42%，为底部图例留合理空间 |
| 图例 / 分页 | 图例保持 `scroll`：图标 9px、间距 10px、字号 11px，分页箭头 8px / 页码 10px（compact） |
| 文案 | 空态列表与「万物皆可插件」说明的上下间距 `mt-2` → `mt-1`；说明保持小字 |
| 不改动 | 数据口径、留痕链接、其余卡片与布局均不变 |

## 三、改动面

| 文件 | 动作 |
|---|---|
| `plugin_host/templates/home_dashboard.html` | 插件分布卡片去 `h-100`、图表 240px、文字间距收紧 |
| `charts/echarts/renderer.py` | 饼图 option：紧凑图例 / 分页 / 半径 |
| 文档 | 本文件 + roadmap / README / constraints |

无新表、无迁移、无数据与交互变化。

## 四、验收口径

1. 插件分布卡片高度随内容收紧，底部无大片空白；
2. 环形图、图例、分页箭头、说明文案间距紧凑，无重叠 / 截断；
3. 组织人员卡片与其余工作台内容不受影响。
