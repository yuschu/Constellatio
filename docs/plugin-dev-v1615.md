# 插件开发文档：v1.6.15 公告中心双卡片改版

> 关联：notice（公告中心）
> 版本：v1.6.15 · 文档日期：2026-10-24
> 状态：**✅ 已实现并部署**（notice 6 项测试通过；全量 235/237 见说明）

## 一、需求

1. 移除左侧公告列表表格，保留左右双卡片，顶部对齐、统一卡片规格；
2. 左卡：标题、发布人、已读人数、公告状态、发布时间，新增白底蓝字【已读】按钮（查看已读人员）；
3. 右卡：公告标题、元信息（发布人 / 时间 / 已读人数 / 公告类型）、正文、底部蓝色「返回列表」；
4. 页面标题、侧栏、右上【+ 发布公告】不变；业务逻辑不变。

## 二、设计口径

| 项 | 决策 |
|---|---|
| 布局 | `row g-4`：左 `col-lg-4` 信息卡、右 `col-lg-8` 详情卡，均 `r-card h-100`；窄屏堆叠 |
| 左卡 | 信息项 `d-flex flex-column gap-2`，每项「灰色小标签 + 值」；状态用 `r-badge--green` 已读标签 |
| 已读按钮 | `r-btn r-btn--ghost`（v1.6.14 白底蓝字蓝边）→ Bootstrap modal 展示已读人员（姓名 / 账号 / 已读时间，空态文案） |
| 切换公告 | 列表表格移除后，用左卡「切换公告」下拉保留切换能力（change 事件跳 `?notice=<id>`，无内联绑定） |
| 右卡 | 标题 h2；元信息一行小字弱化（发布人 / 时间 / 已读人数 / 置顶或普通）；正文独立区块（行高 1.9、内边距、`--r-paper-2` 底）；`mt-auto` 置底「返回列表」蓝色链接 |
| 视图 | 增加 `readers`（当前公告已读人员，按时间倒序）；其余查询 / 已读幂等 / 权限 / 旧链接 302 不变 |
| 不变 | 发布流程、跳转、权限与数据字段 |
