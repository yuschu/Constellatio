# 插件开发文档：v1.6.5 指标卡按钮底部居中与基线对齐

> 关联：plugin_host（工作台共享看板模板）
> 版本：v1.6.5 · 文档日期：2026-10-23
> 状态：**✅ 已实现并部署**（按要求未跑自动化测试，功能验证交由负责人）

## 一、需求

核心数据看板四张卡片（待我审批 / 考勤概况 / 流程发起 / 插件运行状态）内的操作按钮：

1. 卡片内按「标题 → 图表 → 统计文字 → 按钮」纵向排布；
2. 操作按钮放在卡片底部，在卡片宽度内**水平居中**、在底部区域内**垂直居中**；
3. 四张卡片底部的按钮**保持同一水平基线**（不受卡片内图表 / 文字高度差异影响）。

其余布局、图表、交互不变。

## 二、设计口径

| 项 | 决策 |
|---|---|
| 等高 | 卡片已有 `h-100`，同一行四列随 Bootstrap 拉伸等高 |
| 纵向排布 | 卡片容器加 `d-flex flex-column`，内容按顺序堆叠 |
| 按钮置底 | 按钮包 `d-flex justify-content-center align-items-center mt-auto pt-2`：`mt-auto` 占满剩余空间把按钮压到底部 |
| 基线一致 | 四张卡等高 + 按钮统一 footer → 四按钮底部对齐；告警徽标移出 footer（放在统计文字下方），避免 footer 换行导致按钮高度不一致 |
| 不改动 | 图表高度、卡片内容、点击跳转、数据与交互均不变 |

## 三、改动面

| 文件 | 动作 |
|---|---|
| `plugin_host/templates/home_dashboard.html` | 四卡 `d-flex flex-column`；按钮 footer 居中置底；告警徽标移出 footer |
| 文档 | 本文件 + roadmap / README / constraints |

无新表、无迁移、无 Python / CSS 规则变化（复用 Bootstrap 工具类）。

## 四、验收口径

1. 四张卡片的按钮均在卡片底部水平居中；
2. 桌面同一行内四个按钮处于同一水平线（含带告警徽标的卡片）；
3. 图表 / 文字高度不同的卡片，按钮基线仍一致；
4. 窄屏堆叠时每张卡按钮仍在各自底部居中。
